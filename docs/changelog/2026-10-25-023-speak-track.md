# 跟读模式：看词朗读、Azure 打分、读错进错音库

日期：2026-10-25

在原来的拼写练习之外加了第二套独立的训练系统「跟读」，练口语发音。两套系统用同一份词典数据，但进度、记录、错题库、复习队列全部分开。

## 入口

- 首页改成两栏：上面「拼写」（今日复习 + 继续学习），下面「跟读」（错音复习 + 继续跟读），各自记住自己的词典和章节，并同步到账号。
- 点开任意一本 PTE 词典，章节列表上方多了「拼写 / 跟读」切换；同一章在两种模式里是同样的 20 个词。
- 跟读模式会跳过在其他 PTE 词典里已经读过的词（和拼写模式跳过已打过的词是同一个规则，但两边互不影响）。

## 一个词的流程（电脑）

- 显示单词和音标（跟读模式强制显示），自动开麦；读完后 Azure 自动检测结束并出分。
- 及格线固定 80 分。整体分低于 80、Azure 没听出这个词、或短语里任一个词不及格都算错。
- 及格：绿色分数显示约半秒后自动进入下一个词。
- 不及格：自动放一遍有道原声；显示按顺序排列的音素格子（绿 / 黄 / 红）和分数，可以听自己刚才的录音对比。录音只留在内存里，不上传。
- 第一次读的结果决定对错，和拼写的「第一遍正确率」口径一致；进了错音库之后可以继续重读到及格再走。
- 按键：空格重读，Enter 下一个（没读就按 Enter 算跳过，记为错），P 放原声，R 放自己的录音。
- 几秒没出声会自动重新开麦，不算错。
- Azure 不可用（没配 key、额度用完、网络问题）或没有麦克风权限时，当前词出现「读对了 (Y) / 读错了 (N)」自评按钮，练习不中断，记录标注为手动评分。

## 口音

- 默认按英音（en-GB）打分，练习页顶部可以切成美音（en-US）。音标、原声、打分三者跟着一起切。
- Azure 只对 en-US 提供音素名；en-GB 只给按顺序的音素分数。英音模式下用词典音标按音素数对位：数目一致就把音标写进格子，不一致只显示位置。美音模式下能直接标出读错的音素和「你读成了什么」。

## 错音库与复习

- 新的复习卡类型 `speak`，走 FSRS，和拼写的 `word` 卡互不影响；同一个词可以同时在错词本和错音库里。
- 错题本多了「错音」tab：历次得分、最近一次读错的音素和分数。
- 到期的错音复习是强制的，但只拦跟读章节，不影响拼写。首页「练习中错题」里多了「错音库」卡片，可以随时全部再读一遍。
- 章节结算页在跟读模式下显示平均分，错词带分数，多一个「只重读错音词」按钮（重读不再计入章节记录，也不改变错音卡）。

## 数据与接口

- 新表 `speak_record`：每次朗读一行（词、词典、章节、得分、是否及格、是否第一次、是否手动、口音、音素分、录音时长）。录音时长方便查 Azure 当月用了多少额度。
- `review_card` 加 `detail` 字段（speak 卡的得分和音素）；`user_preference` 加 `speak_dict` / `speak_chapter`。
- 新接口：`GET /api/speech/token`（给浏览器发 10 分钟的 Azure token，复用现有的 `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION`）、`POST /api/records/speak`；`/api/words/practiced?mode=speak`、`/api/review/*?type=speak`。
- 跟读的章节记录复用 `chapter_record`，dict 填 `<词典>@speak`。
- 新依赖 `microsoft-cognitiveservices-speech-sdk`，只在跟读页面按需加载。

## 额度

Azure 免费档每月 5 小时语音识别，一个词连前后静音约 3 秒，约 6000 个词 / 月。
