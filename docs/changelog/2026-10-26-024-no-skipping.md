# 不对不能走：拼写和跟读都去掉跳词

日期：2026-10-26

- 拼写模式：去掉错 4 次后出现的 Skip 按钮、Ctrl+Shift+方向键跳词、点击上一词 / 下一词跳转。上一词 / 下一词只作显示。一个词必须打对才进入下一个。
- 跟读模式：去掉 Enter「下一个」。没及格的词只能按空格或 Enter 再读，读到 80 分以上自动进入下一个。第一遍的结果照旧决定是否进错音库。
- 跟读的技术修正：去掉已废弃的 800 毫秒结束静音参数（它让 Azure 对单词返回 `NoMatch: NotRecognized`），改为静音 1 秒算说完；麦克风改为自己采集并推 16kHz 音频给 SDK（SDK 自带的麦克风通道在用户手势之外建 AudioContext，会一直挂起）；识别 20 秒无结果自动切手动判断；监听时显示实时音量条，Azure 没听到时显示诊断行。
