# FIB / WFD 改为自己的题库，按导入日期分章

日期：2026-10-20

- 导入的 FIB / WFD 不再直接进错题，而是进**题库**（新表 `practice_item`）。只有单词（`/api/v1/review-words`）直接进错题集（强制复习）。
- 首页「PTE 词汇」最前面加两张题库卡片：**FIB 固定搭配**、**WFD 拼写**。点开按**导入日期**分组：WFD 同一天每 **5** 句一组，FIB 每 **10** 条一组。
- 练一组和学词典一样：第一遍打错的进 FIB / WFD 错题（FSRS 建议复习，不强制）；打对的不进。练新的一组前要先完成当天的单词复习。
- 完成一组后可直接「下一组」。组号由日期和组序生成（如 2026-10-20 第 1 组 = `2026102001`），以后补导入更早日期的题也不会打乱已练标记。
- 导入接口 `POST /api/v1/fib`、`/api/v1/wfd` 改为写入题库，可选 `date` 参数（默认今天，Australia/Perth）；重复的句子跳过。新增 `GET /api/bank/:type`。
- 「练习中错题」里的 FIB / WFD 改名为「错题」，说明来自练题库时的第一遍错误。
- 修复：下一题是句子时不再去有道预取单词发音。
- 之前导入的 8 条 FIB、25 句 WFD 从错题移到题库（导入日期 2026-10-20）。
