# 跟读支持 iPhone（Chrome / Safari）

日期：2026-10-29

- 手机上跟读页可以点一下开始（以前只能按空格，手机上没法开始）。手机上不再显示 空格 / P / R / Y / N 这些快捷键提示，直接点按钮。
- iOS 只允许在用户点击时启动音频，而麦克风授权是点击之后才返回的，所以麦克风的音频通道会一直停着。现在点「开始跟读」时就先把音频通道打开；如果还是停着（比如接了电话、切到别的 App 再回来），会显示「点一下打开麦克风」，点一下就恢复。
- iOS 上录音按手机原生采样率采集，再在页面里转成 16 kHz 送给 Azure（iOS 上直接要 16 kHz 可能录到静音）。
- 拼写在手机上早已支持（见 018）。
