# 跟读打分改用综合分，加上流利度和语调

日期：2026-10-30

- 原因：以前大字分数只是 Azure 的「准确度」（每个音对不对），Azure 知道原文，只核对音素，所以分数比 PTE 高很多；PTE 扣得最多的停顿、卡顿、重音和语调完全没算。
- 现在大字是 Azure 的综合分（PronScore），由准确度、流利度、完整度和语调合成。美音打分时打开了语调评估（重音、语调、节奏）；英音 Azure 不支持语调，只有准确和流利。
- 分数下面列出「准确 · 流利 · 语调」三项，低于 80 的标红。
- 及格：综合分 ≥ 80，并且每个词都 ≥ 80、没有漏读。没过时写出原因，例如「没过：about 53 分」或「没过：总分 74（流利 70、语调 65）」。
- 从这次起记录里存的是综合分，和以前的准确度分不完全可比。
- 分数仍然不等于 PTE 分：PTE 用 Pearson 自己的引擎，没有公开换算方法。
