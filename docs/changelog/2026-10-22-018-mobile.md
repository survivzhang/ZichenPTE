# 手机打开自己的首页；练习页支持手机键盘

日期：2026-10-22

- 去掉上游留下的手机跳转。以前屏幕宽度 ≤ 600px（手机竖屏）时，所有页面都会跳到 `/mobile`，那是原作者 Qwerty Learner 的宣传页，按钮都链到 qwerty.kaiyi.cool。现在手机上也打开首页、错题本、统计这些正常页面。宣传页和它的图片已删除。
- `index.html` 去掉原作者网站的 canonical、Open Graph、结构化数据等链接，标题改成「Qwerty Learner · PTE」，并设成不让搜索引擎收录。
- 手机和平板（触屏设备）的练习页改用一个隐藏的输入框接收输入：
  - 点「点一下开始」或 Start 会弹出系统键盘。练习中点页面任意空白处也会弹出键盘；键盘收起后，底部会出现「点这里打开键盘」。
  - 支持 Android 键盘边打边组字的方式，也支持选候选词一次输入多个字母。已关掉自动大写和自动纠错。
  - 电脑上还是原来的键盘监听，不受影响。
- 手机排版：首页导航、练习页工具栏（换行显示，Start 不会被挤出屏幕）、统计卡片缩小；手机上不显示页脚；单词字号按屏幕宽度封顶，长单词不会超出屏幕。
